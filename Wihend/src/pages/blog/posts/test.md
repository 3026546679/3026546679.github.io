要想**最快地练出肌肉（增肌）** ，建议每周训练 **3～5次**，具体安排取决于你的**恢复能力、训练计划和饮食情况**。下面是科学推荐的频率和建议：

* * *

## 🧠 结论先行：

**最佳频率**：

> 每个肌群每周训练 **2次**，每周总训练 **3～5次** 为最佳增肌频率。

* * *

## ✅ 为什么这样安排？

-   肌肉不是训练时长得，而是**训练后的休息和修复时长出来的**。
-   一次训练后肌肉需要 **48小时以上** 恢复时间。
-   多次刺激比“炸一次”效果更好，能让合成激素持续活跃。

* * *

## 💪 推荐训练频率

```markdown
| 训练经验 | 周训练次数 | 每周每个肌群刺激次数 | 说明               |
| ---- | ----- | ---------- | ---------------- |
| 新手   | 3次    | 每个肌群2次     | 全身训练/推拉腿         |
| 进阶   | 4～5次  | 每个肌群2次     | 分化训练（如胸+三头，背+二头） |
| 高阶   | 5～6次  | 每个肌群2～3次   | 精细分化（如五分化）       |
```

* * *

## 🗓️ 示例训练计划（中级增肌）

### 一周五练：推拉腿（PPL）

```markdown
| 星期 | 内容        |
| -- | --------- |
| 周一 | 推：胸、肩、三头  |
| 周二 | 拉：背、二头    |
| 周三 | 腿：大腿、臀、小腿 |
| 周四 | 休息        |
| 周五 | 推         |
| 周六 | 拉         |
| 周日 | 休息        |
```

> 优点：恢复好、刺激足、增长快。

* * *

## 🍗 补充建议

-   **睡眠**：每天至少 7 小时，最好 8 小时。
-   **饮食**：蛋白质足够（每公斤体重 × 1.6～2.2 克蛋白质），碳水别省。
-   **逐步加重**：保持进步，肌肉才会增长（渐进式超负荷）。
